
# Spill The Tea ☕

**Anonymous Tea Wall – Frontend Project**

Spill The Tea is a lightweight, anonymous tea-sharing web app where users can post short “tea” (confessions/gossip), react to others, and view trending posts.
All data is stored locally in the browser using `localStorage` — no accounts, no backend, fully client-side.

## ✨ Features

* 🫖 Post anonymous “tea”
* 🔥 Trending section (auto-sorted by reactions)
* ❤️ Emoji reactions (heart, laugh, fire)
* 📊 Live stats (teas spilled & reactions)
* 🎨 Modern UI with gradients, glow effects & custom fonts
* 💾 Local storage persistence (your teas stay on refresh)
* 📱 Responsive layout (mobile-friendly)

## 🛠 Tech Stack

* HTML
* Tailwind CSS (CDN)
* Custom CSS
* Vanilla JavaScript
* `localStorage` for persistence
* Canvas Confetti (micro-interactions)

## 🚀 How to Run Locally

1. Clone the repo:

```bash
git clone https://github.com/Saad4Dev/SpillTheTea.git
```

2. Open the folder:

```bash
cd SpillTheTea/SpillTheTeaLockedIn
```

3. Run with Live Server (VS Code)
   or
   Open `index.html` directly in your browser.
